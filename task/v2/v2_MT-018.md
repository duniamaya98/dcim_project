## 5. Multi-Model Voting

```python
# Dari services/anomaly_service.py
iso_pred = isolation_forest.predict(X_scaled)
lof_pred = local_outlier_factor.predict(X_scaled)
svm_pred = one_class_svm.predict(X_scaled)

votes = (
    (iso_pred == -1).astype(int)
    + (lof_pred == -1).astype(int)
    + (svm_pred == -1).astype(int)
)

predictions = np.where(votes >= 2, -1, 1)  # Majority voting
```

## 6. Drift Detection

```python
# Dari features/drift_detector.py
drift_result = drift_detector.check_drift(X_raw)
z_scores = drift_result["z_scores"]

if drift_result["drift_detected"]:
    if max(z_scores) > 5.0:
        drift_level = "severe_drift"
    else:
        drift_level = "moderate_drift"
else:
    drift_level = "stable"
```
