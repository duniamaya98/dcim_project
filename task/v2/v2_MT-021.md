## 3. Training Pipeline

```

        ↓
Training Orchestrator
        ↓
Feature Pipeline
        ↓
Ensemble Model Training (IF + LOF + SVM)
        ↓
Artifact Packaging
        ↓
Model Registry (Candidate)
        ↓

        ↓
Production Model
```

## 5. Artifact Structure

```

    lof.pkl
    ocsvm.pkl
```

Metadata menyimpan:
- version
- training_window
- validation_anomaly_ratio
- dataset_snapshot.sha256
- random_seed
- code_revision
