## 3. Architecture

```
Incident Data
        ↓
RootCauseResult Contract
        ↓
Causal Topology Manager (DFS, depth 3)
        ↓
Composite Scoring Engine
    ├── topology_score (0.30)
    ├── domain_strength (0.25)
    ├── persistence_ratio (0.20)
    ├── trend_weight (0.10)
    ├── anomaly_ratio (0.10)
    └── drift_ratio (0.05)
        ↓
Softmax Normalization
        ↓
Root Domain + Causal Chain + Explanation
```

---

## 4. RCA Modes

### Reactive Mode (analyze)

```python
result = RCAEngine.analyze(incident)
# Menerima incident yang sudah terjadi
# Menggunakan semua scoring components
```

### Forward Mode (analyze_forward)

```python
result = RCAEngine.analyze_forward(forecast_payload)
# Menerima projeksi forecast 24/48 jam
# Menjawab: "Kalau forecast menunjukkan failure, rantai penyebabnya apa?"
```

### Hybrid Mode (analyze_hybrid)

```python
result = RCAEngine.analyze_hybrid(incident, forecast_payload, forecast_weight=0.4)
# Gabungkan reactive + forward
# p_hybrid = (1-w) * p_reactive + w * p_forward
```

## 6. Composite Scoring Formula

```
root_score(domain) =
    0.30 * topology_score
  + 0.25 * domain_strength
  + 0.20 * persistence_ratio
  + 0.10 * trend_weight
  + 0.10 * anomaly_ratio
  + 0.05 * drift_ratio
```
